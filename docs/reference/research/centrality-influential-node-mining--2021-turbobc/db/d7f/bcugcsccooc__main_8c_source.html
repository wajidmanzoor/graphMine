21/*
22* Betweenness centrality (BC)
23* Single precision (float data type)
24* TurboBC:bcugcsccooc_main.c
25*
26* This program:
27* 1) Reads a real (non-complex) sparse matrix from a Matrix Market (v. 2.0) file.
28* 2) computes a sequential BC for unweighted, and weighted
29* graphs with sparse matrices in the CSC format.
30* 3) computes a single precision GPU-based parallel BC
31* for undirected and directed graphs with sparse
32* matrices in the CSC and COOC formats.
33*
34* Compile: make with Makefile
35*
36* Run: ./exec /lclhome/oarti001/documents/SpMVcuda/MMdataFiles/[filename] --w --ug --format --p --nr --rs --repet --seq
37*
38* --w is an integer equal to 1 if there is a weighted graph, and 0 otherwise,
39* --ug is an integer equal to 1 if there is an undirected graph (matrix A is symmetric),
40* and equal to 0 otherwise,
41* --format: integer equal to: 0 (CSC_sc), 1 (CSC_wa), 2 (COOC_sc)
42* --p: integer equal to 1 to print results, 0 otherwise,
43* --nr: number root vertices to compute the BC (also source vertex)
44* --rs: if nr =1, rs is the root vertex.
45* --repet: the number of computations of BC to obtain average time.
46* --seq: 1 when the sequential BC is computed, 0 otherwise
47*
48* run with the: run_bcugcsccooc.sh script
49 *
50*/
