Detailed Description

template<class BuffType>
class SubgraphContainer< BuffType >

This is a templated subgraphs container.

It uses two buffers: wrBuff, rdBuff to write and process subgraphs respectively. The required template class is a buffer class, where user can specify data required for each subgraph
