Computes a block size in number of threads for a CUDA kernel using a occupancy-promoting heuristic.

Parameters
attributesThe cudaFuncAttributes corresponding to a global function of interest on a GPU of interest.
propertiesThe cudaDeviceProp corresponding to a GPU on which to launch the global function of interest.
Returns
A CUDA block size, in number of threads, which the resources of the GPU's streaming multiprocessor can accomodate and which is intended to promote occupancy. The result is equivalent to the one performed by the "CUDA Occupancy Calculator".
Note
The global function of interest is presumed to use 0 bytes of dynamically-allocated shared memory.

Computes a block size in number of threads for a CUDA kernel using a occupancy-promoting heuristic. Use this version of the function when a CUDA block's dynamically-allocated shared memory requirements vary with the size of the block.

Parameters
attributesThe cudaFuncAttributes corresponding to a global function of interest on a GPU of interest.
propertiesThe cudaDeviceProp corresponding to a GPU on which to launch the global function of interest.
block_size_to_dynamic_smem_bytesA unary function which maps an integer CUDA block size to the number of bytes of dynamically-allocated shared memory required by a CUDA block of that size.
Returns
A CUDA block size, in number of threads, which the resources of the GPU's streaming multiprocessor can accomodate and which is intended to promote occupancy. The result is equivalent to the one performed by the "CUDA Occupancy Calculator".
