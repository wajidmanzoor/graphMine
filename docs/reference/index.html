How to trace an operation

Move from stable API to original kernel.

  1. Public problem class Find the class and inspect its constructor, supports(), and run().
  2. Problem facade Follow references from run() into normalization and backend dispatch.
  3. Backend adapter Open the selected `.cpp` or `.cu` adapter to see format conversion and launch setup.
  4. Research source Continue into the matching problem/paper tree to inspect the exact host and device functions.
About generated documentation

The indexes are generated directly from the committed source with Doxygen. Preserved upstream code is documented as written: existing comments are shown, and otherwise the signature, declaration, definition, references, and full source remain available. Licensing and pinned source provenance are recorded in THIRD_PARTY.md.
