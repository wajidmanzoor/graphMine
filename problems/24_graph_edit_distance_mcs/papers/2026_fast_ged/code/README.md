# FAS-GED

## Overview

FAS-GED (Fast Approximate Graph Edit Distance) is a project designed to efficiently compute the Graph Edit Distance (GED) between structured graphs using CUDA for GPU acceleration. This project is useful for applications in pattern recognition, graph matching, and machine learning.

## Features
- **CUDA Acceleration**: Leverages GPU computation for faster GED calculations.
- **Scalability**: Handles large graph datasets efficiently up to 1000 nodes.
- **Customizable Parameters**: Allows fine-tuning of GED computation settings for a better accuracy/scalability.

## Installation

1. Clone the repository:
    ```bash
    git clone https://gitlab.jsc.fz-juelich.de/dabah2/fast-ged.git
    cd fast-ged
    ```

2. Build the project using the Makefile:
    ```bash
    make
    ```

3. Executes the code with default test inputs in ./data:
    ```bash
    make run
    ```
4. Cleans up build artifacts:
    ```bash
    make clean
    ```
## Usage

Run the main executable to compute GED:
```bash
java -jar ./bin/graph-ged-super.jar 2 2 1 1 ./data/ggraph1.gxl ./data/ggraph2.gxl ./slurm_result/output.txt MUTA 500000
```


### Arguments 
```
arg1 cost of node substitution 
arg2 cost of node deletion and insertion 
arg3 cost of edge substitution 
arg4 cost of edge deletion and insertion 
arg5 Graph1: ./data/ggraph1.gxl 
arg6 Graph2: ./data/ggraph2.gxl
arg7 path to the output file 
arg8 MUTA (test benchmark)
arg9 50000 is the number of kept nodes during the search process.. (for higher accuracy increase arg9) 
```

### Using `/py_scripts/networkx_ged.py` for Comparison with NetworkX library

To compare the performance of FAST-GED with NetworkX's GED implementation, you can use the `networkx_ged.py` script provided in the repository.

#### Steps:

1. Run the script with two graph files in GXL format:
    ```bash
    python ./py_scripts/networkx_ged.py 1000000 8 # kept-nodes, size of random graph generated by the script
    ```

2. The script will compute the Graph Edit Distance using NetworkX and output the result to the console.
3. The script also includes a function to export NetworkX graphs as GXL files that can be used with FAS-GED. 
4. The `./scripts/` directory contains examples demonstrating how to load the modules and execute the code on the JSC JUWELS machine.
