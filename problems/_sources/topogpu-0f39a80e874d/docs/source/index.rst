TopoGPU – GPU-accelerated persistent homology for image data
=============================================================

TopoGPU computes persistence diagrams of 2D images and 3D volumes on the GPU,
with a Python module and a command-line tool. It is the official implementation of
*GPU-Accelerated Computation of Persistent Homology for Topological Analysis of Image Data*,
IEEE TPAMI 2026 (`DOI 10.1109/TPAMI.2026.3741473 <https://doi.org/10.1109/TPAMI.2026.3741473>`_).
