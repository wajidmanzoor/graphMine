# Converts DIMACS flow graphs into ECLgraph CSR format

This converter takes graphs generated by [DIMACS generators](http://archive.dimacs.rutgers.edu/pub/netflow/generators/network/), such as AC, Genrmf, and Washington, and converts them into the CSR format ECL-MaxFlow uses.

To compile:

    make

To run: 

    ./dimacsflow2ecl <input_file_name> <output_file_name>
