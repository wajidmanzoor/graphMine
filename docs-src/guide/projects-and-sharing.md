# Projects and sharing

Share selected input or result snapshots while keeping the surrounding conversation private.

Open **Projects** or **Project workspaces**, create a project, and select it. A project can hold input snapshots, result snapshots, annotations, and named views. Its owner controls membership and read-only links. Existing members can be viewers or editors; a viewer reads, while an editor can publish and annotate.

## Share a snapshot

From a conversation, choose **Share input to project** or **Share result to project**, select the project, and give the snapshot a name. An input share copies the selected input and provenance. A result share includes the saved result, its inputs, plan, and provenance. Your conversation messages remain private.

These are independent snapshots. Changing or deleting the private source does not automatically remove a shared copy. Project storage is charged to the project owner. **Use a project input** copies a shared input into your own conversation for further analysis.

## Read-only links

A project owner can create a read-only link for a selected snapshot and choose its expiry within the offered range. Anyone holding the link can read that complete snapshot, including a result's retained inputs and plan. The link does not expose project discussions or membership.

Review the snapshot before sharing its link. Revoke a link or delete the shared snapshot from the project's controls when access should end. A read-only link cannot edit the source conversation.
