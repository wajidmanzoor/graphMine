# GraphMine

Ask a question about your graph. See how the answer was computed. GraphMine maps your question to a formal graph problem, runs a compatible compiled CPU or GPU algorithm, and explains the returned facts. Explore the answer in graphs and tables, with its quality, completeness, and input snapshot visible.

[The problem](problem/index.md) explains why ordinary questions need precise contracts. [Use the app](guide/getting-started.md) to choose data, ask a question, and explore results. [Use the library](library/install.md) to build the native runtime and call it from C++, Python, or the command line. [How it works](how-it-works/index.md) follows interpretation, validation, computation, and explanation.

The [family guides](problem/taxonomy.md) define formal problems and show how to run compiled operations. The [code reference](library/code-reference.md) documents the current native APIs and implementation. The [catalog explorer](problem/explorer.md) lists parameters, outputs, backends, and separate research references.

[Watch the demo](https://youtu.be/F5bJvpa3gdQ), [open GraphMine](https://graphmine.autographmine.com/#), or [read the public technical note](research-note/graphmine.pdf).
