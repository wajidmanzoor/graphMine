Data Loading

Overview

Data import is handled in two stages: node creation followed by sequential edge ingestion. We put all the csv files under the data import directory of Neo4j. This directory can be set in the neo4j.conf file using the parameter 'dbms.directories.import'.

For the implementation of MovieLens 32M on Neo4j, we used the original files downloaded from their website. We will read the CSV files unpacked from the downloaded file to complete node and edge imports.

To speed up the import process and future queries, we create B+-tree indices for some node labels.

cypher 
// Unique User IDs
CREATE CONSTRAINT IF NOT EXISTS FOR (u:User) REQUIRE u.userId IS UNIQUE;
// Unique Movie IDs
CREATE CONSTRAINT IF NOT EXISTS FOR (m:Movie) REQUIRE m.movieId IS UNIQUE;
// Unique Genre Names
CREATE CONSTRAINT IF NOT EXISTS FOR (g:Genre) REQUIRE g.name IS UNIQUE;

Movie Nodes, Genre Nodes, and HAS_GENRE Edges

cypher 
CALL apoc.periodic.iterate(
    "LOAD CSV WITH HEADERS FROM 'file:///movielens/ml-32m/movies.csv' AS row RETURN row",
    "CREATE (m:Movie {movieId: toInteger(row.movieId)})
    SET m.title = row.title
    WITH m, row
    UNWIND split(row.genres, '|') AS genreName
    WITH m, genreName WHERE genreName IS NOT NULL AND trim(genreName) <> ''
    MERGE (g:Genre {name: genreName})
    MERGE (m)-[:HAS_GENRE]->(g)",
    {batchSize: 10000, parallel: false}
)

User Nodes and RATED Edges

cypher 
CALL apoc.periodic.iterate(
    "LOAD CSV WITH HEADERS FROM 'file:///movielens/ml-32m/ratings.csv' AS row RETURN row",
    "
    MERGE (u:User {userId: toInteger(row.userId)})
    WITH u, row
    MATCH (m:Movie {movieId: toInteger(row.movieId)})
    MERGE (u)-[r:RATED]->(m)
    SET r.rating = toFloat(row.rating),
    r.timestamp = apoc.date.format(toInteger(row.timestamp), 's', 'yyyy-MM-dd HH:mm:ss')
    ",
    {batchSize: 1000, parallel: false}
)

TAGGED Edges

cypher 
CALL apoc.periodic.iterate(
    "LOAD CSV WITH HEADERS FROM 'file:///movielens/ml-32m/tags.csv' AS row RETURN row",
    "
    MERGE (u:User {userId: toInteger(row.userId)})
    WITH u, row
    MATCH (m:Movie {movieId: toInteger(row.movieId)})
    CREATE (u)-[t:TAGGED]->(m)
    SET t.tag = row.tag,
    t.timestamp = apoc.date.format(toInteger(row.timestamp), 's', 'yyyy-MM-dd HH:mm:ss')
    ",

Q1. Movies Rated by a User

Subcategory: T1.1 One-Hop Neighbors

This query lists the movies directly connected to a selected user by outgoing RATED relationships.

cypher 
MATCH (u:User {userId: 33})-[r:RATED]->(m:Movie)
RETURN m.movieId AS movieId, m.title AS title, r.rating AS rating, r.timestamp AS ratingTime
ORDER BY rating DESC, title;

Equivalent query in GQL standard:

gql 
MATCH (u:ml32m_user {userId: $userId})-[r:ml32m_rated]->(m:ml32m_movie)
RETURN m.movieId AS movieId, m.title AS title, r.rating AS rating, r.timestamp AS ratingTime
ORDER BY rating DESC, title
LIMIT $limit;

Q2. Genres within Two Hops of a User

Subcategory: T1.2 k-Hop Neighborhood

This query follows a selected user to rated movies and then to their genres, returning distinct genres within two hops.

cypher 
MATCH (:User {userId: 33})-[:RATED]->(:Movie)-[:HAS_GENRE]->(g:Genre)
RETURN DISTINCT g.name AS genre
ORDER BY genre;

Equivalent query in GQL standard:

gql 
MATCH (:ml32m_user {userId: $userId})-[:ml32m_rated]->(:ml32m_movie)-[:ml32m_has_genre]->(g:ml32m_genre)
RETURN DISTINCT g.name AS genre
ORDER BY genre
LIMIT $limit;

Q3. Users Exactly Two Rating Hops Away

Subcategory: T1.3 Exact kth-Hop Neighbors

This query finds users exactly two RATED hops away through movies co-rated with a selected user.

Q9. Simple Co-Rating Paths up to Three Hops

Subcategory: T2.5 All Simple Paths up to Length k

This query enumerates acyclic RATED paths between a selected user and movie up to three hops.

cypher 
MATCH p = (:User {userId: 33})-[:RATED*1..3]-(:Movie {movieId: 66})
WHERE all(n IN nodes(p) WHERE single(m IN nodes(p) WHERE m = n))
RETURN p, length(p) AS hopCount
ORDER BY hopCount;

Equivalent query in GQL standard:

gql 
MATCH p = ACYCLIC (:ml32m_user {userId: $userId})-[:ml32m_rated]-{1,3}(:ml32m_movie {movieId: $movieId})
RETURN p, length(p) AS hopCount
ORDER BY hopCount
LIMIT $limit;

Q10. Top Weighted Co-Rating Paths

Subcategory: T2.6 top-K Weighted Paths

This query ranks bounded RATED paths by the sum of rating values along each path.

cypher 
MATCH p = (:User {userId: 33})-[rels:RATED*1..3]-(:Movie {movieId: 66})
WHERE all(n IN nodes(p) WHERE single(m IN nodes(p) WHERE m = n))
WITH p, reduce(total = 0.0, r IN relationships(p) | total + coalesce(r.rating, 0.0)) AS ratingWeight
RETURN p, length(p) AS hopCount, ratingWeight
ORDER BY ratingWeight DESC;

Equivalent query in GQL standard:

gql 
MATCH p = ACYCLIC (:ml32m_user {userId: $userId})-[:ml32m_rated]-{1,3}(:ml32m_movie {movieId: $movieId})
WITH p, reduce(total = 0.0, r IN relationships(p) | total + coalesce(r.rating, 0.0)) AS ratingWeight
RETURN p, length(p) AS hopCount, ratingWeight
ORDER BY ratingWeight DESC
LIMIT $limit;

Q11. Three-Movie Triangle by Shared Genres

Subcategory: T3.1 Triangle Detection

This query finds three movies where every pair shares at least one genre through HAS_GENRE relationships.

cypher 
MATCH (a:Movie)-[:HAS_GENRE]->(:Genre)<-[:HAS_GENRE]-(b:Movie)
MATCH (b)-[:HAS_GENRE]->(:Genre)<-[:HAS_GENRE]-(c:Movie)
MATCH (c)-[:HAS_GENRE]->(:Genre)<-[:HAS_GENRE]-(a)
WHERE a.movieId < b.movieId AND b.movieId < c.movieId
RETURN DISTINCT a.title AS movieA, b.title AS movieB, c.title AS movieC;

Equivalent query in GQL standard:

gql 
MATCH (a:ml32m_movie)-[:ml32m_has_genre]->(:ml32m_genre)<-[:ml32m_has_genre]-(b:ml32m_movie)
MATCH (b)-[:ml32m_has_genre]->(:ml32m_genre)<-[:ml32m_has_genre]-(c:ml32m_movie)
MATCH (c)-[:ml32m_has_genre]->(:ml32m_genre)<-[:ml32m_has_genre]-(a)
WHERE a.movieId < b.movieId AND b.movieId < c.movieId
RETURN DISTINCT a.title AS movieA, b.title AS movieB, c.title AS movieC
LIMIT $limit;

Q12. Four-Movie Square by Shared Genres

Subcategory: T3.2 Square Detection

This query finds four movies connected in a cycle where each adjacent pair shares a genre.

cypher 
MATCH (a:Movie)-[:HAS_GENRE]->(:Genre)<-[:HAS_GENRE]-(b:Movie)
MATCH (b)-[:HAS_GENRE]->(:Genre)<-[:HAS_GENRE]-(c:Movie)
MATCH (c)-[:HAS_GENRE]->(:Genre)<-[:HAS_GENRE]-(d:Movie)
MATCH (d)-[:HAS_GENRE]->(:Genre)<-[:HAS_GENRE]-(a)
WHERE a.movieId < b.movieId AND a.movieId < c.movieId AND a.movieId < d.movieId
  AND b <> c AND b <> d AND c <> d
RETURN DISTINCT a.title AS movieA, b.title AS movieB, c.title AS movieC, d.title AS movieD;

Equivalent query in GQL standard:

gql 
MATCH (a:ml32m_movie)-[:ml32m_has_genre]->(:ml32m_genre)<-[:ml32m_has_genre]-(b:ml32m_movie)
MATCH (b)-[:ml32m_has_genre]->(:ml32m_genre)<-[:ml32m_has_genre]-(c:ml32m_movie)
MATCH (c)-[:ml32m_has_genre]->(:ml32m_genre)<-[:ml32m_has_genre]-(d:ml32m_movie)
MATCH (d)-[:ml32m_has_genre]->(:ml32m_genre)<-[:ml32m_has_genre]-(a)
WHERE a.movieId < b.movieId AND a.movieId < c.movieId AND a.movieId < d.movieId
  AND b <> c AND b <> d AND c <> d
RETURN DISTINCT a.title AS movieA, b.title AS movieB, c.title AS movieC, d.title AS movieD
LIMIT $limit;

Q26. Degree Centrality on the User-Movie Rating Graph

Subcategory: T5.1 Degree Centrality

This query projects the bipartite User-Movie rating graph and ranks nodes by degree centrality.

cypher 
CALL gds.graph.project(
  'ML32MRatingGraph',
  ['User', 'Movie'],
  {RATED: {type: 'RATED', orientation: 'UNDIRECTED'}}
);

CALL gds.degree.stream('ML32MRatingGraph')
YIELD nodeId, score
RETURN labels(gds.util.asNode(nodeId)) AS labels,
       coalesce(gds.util.asNode(nodeId).userId, gds.util.asNode(nodeId).movieId) AS id,
       gds.util.asNode(nodeId).title AS title,
       score
ORDER BY score DESC;

Equivalent query in GQL standard:

gql 
MATCH (n:ml32m_user|ml32m_movie)
OPTIONAL MATCH (n)-[r:ml32m_rated]-()
WITH n, count(r) AS score
RETURN coalesce(n.userId, n.movieId) AS id,
       n.title AS title,
       score
ORDER BY score DESC
LIMIT $limit;

Q27. PageRank on the User-Movie Rating Graph

  {RATED: {type: 'RATED', orientation: 'UNDIRECTED'}}
);

CALL gds.pageRank.stream('ML32MRatingGraphPageRank')
YIELD nodeId, score
RETURN labels(gds.util.asNode(nodeId)) AS labels,

       gds.util.asNode(nodeId).title AS title,

ORDER BY score DESC;

Q31. Find movies that span at least 3 genres and have at least 50 user ratings, return top-10 movies in descending order of their rating count, along with the list of genres and the rating count

Subcategory: T4.2 Grouped Node Degree Statistics by Label; T4.3 Ungrouped Edge Count and Property Statistics

This query retrieves the top 10 most rated movies that belong to at least 3 genres and have received at least 50 user ratings, showing their titles, genres, and rating counts.

cypher 
MATCH (m:Movie)-[:HAS_GENRE]->(g:Genre)
MATCH (u:User)-[r:RATED]->(m)
WITH m, collect(DISTINCT g.name) AS genres, count(DISTINCT r) AS ratingCount
WHERE size(genres) >= 3 AND ratingCount >= 50
RETURN m.title AS movie, genres, ratingCount
ORDER BY ratingCount DESC
LIMIT 10;

Equivalent query in GQL standard:

MATCH (u:ml32m_user)-[r:ml32m_rated]->(m)

WHERE size(genres) >= 3 AND ratingCount >= 50
RETURN m.title AS movie, genres, ratingCount
ORDER BY ratingCount DESC
LIMIT 10

Q32. Find top-20 movies with the highest number of genres + tags, return this number, list of their genres, and list of their tags

Subcategory: Other

This query finds the top 20 movies with the largest combined count of unique genres and tags, returning the total count along with their genre and tag lists.

cypher 
MATCH (m:Movie)
OPTIONAL MATCH (m)-[:HAS_GENRE]->(g:Genre)
OPTIONAL MATCH (:User)-[t:TAGGED]->(m)
WITH m,
COLLECT(DISTINCT g.name) AS genres,
COLLECT(DISTINCT t.tag) AS tags,
SIZE(COLLECT(DISTINCT g.name)) + SIZE(COLLECT(DISTINCT t.tag)) AS total
ORDER BY total DESC
LIMIT 20
RETURN m.title AS movieTitle, total, genres, tags;

Equivalent query in GQL standard:

gql 
MATCH (m:ml32m_movie)
OPTIONAL MATCH (m)-[:ml32m_has_genre]->(g:ml32m_genre)
OPTIONAL MATCH (:ml32m_user)-[t:ml32m_tagged]->(m)
WITH m,
     collect(DISTINCT g.name) AS genres,
     collect(DISTINCT t.tag) AS tags,
     size(collect(DISTINCT g.name)) + size(collect(DISTINCT t.tag)) AS total
ORDER BY total DESC
LIMIT 20
RETURN m.title AS movieTitle, total, genres, tags

Q33. Find (user, movie) pairs where the movie is first rated by the user, and then tagged by the user, return 10 such user-movie pairs with the latest timestamps, along with the rating and the list of tags (tagged after the rating)

Subcategory: Other

This query retrieves the top 10 user-movie pairs where the user rated a movie before tagging it, sorted by the rating timestamp.

cypher 
MATCH (u:User)-[r:RATED]->(m:Movie)<-[t:TAGGED]-(u)
WHERE r.timestamp < t.timestamp
WITH u.userId AS userId, m.title AS movieTitle, r.rating AS rating, r.timestamp AS ratingTime,
COLLECT(DISTINCT t.tag) AS tags
RETURN userId, movieTitle, rating, tags
ORDER BY ratingTime DESC
LIMIT 10;

     collect(DISTINCT t.tag) AS tags

LIMIT 10
