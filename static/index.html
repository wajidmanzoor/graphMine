New empty dataset

Starts with no conversations; add them with ＋ Add. Steps written here have no model context, so an export puts them in needs-context.jsonl for the pipeline to complete. The dataset is saved under studio-datasets/ in the data root.

Export new dataset version

The source dataset is never modified. The export contains sft/<model>/<split>.jsonl, sft-index.jsonl, annotations.jsonl (tags, review, notes), needs-context.jsonl, changes.jsonl and a manifest.json with SHA-256 fingerprints. Unchanged rows are byte-identical to the source.
